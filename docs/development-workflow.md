# Development Workflow

1. Select a ticket.
2. Create a feature or bugfix branch.
3. Read the existing code before changing it.
4. Implement the smallest correct solution.
5. Add/update tests.
6. Run the full test suite.
7. Commit with a meaningful message.
8. Push the branch.
9. Open a PR.
10. Address review comments.
11. Merge only after CI passes.

Examples:
feature/ORD-101-customer-api
bugfix/BUG-77-duplicate-order
